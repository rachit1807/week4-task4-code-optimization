02 / ASYNCHRONOUS CODE

THE WORKLOAD

A small commerce backend.

Generate customers and four orders per customer, then calculate paid order counts and totals in integer cents. Both implementations preserve customer order and return zero totals for customers without paid orders.

THE MEASUREMENT

Warm up. Alternate. Compare.

Both implementations receive three warm-ups. Measured rounds alternate execution order to reduce ordering bias. The reported value is the median; output equality is checked outside the timed interval.

THE ENVIRONMENT

Your device is the laboratory.

Benchmarks run in a background Web Worker to keep the interface responsive. Browser, device, thermal state and background tasks affect results. Small inputs may show more noise.

MEMORY & PROFILING

Look beyond the stopwatch.

The Node.js benchmark script also records heap deltas and heap snapshots with explicit garbage collection. Browser memory is deliberately not estimated. See the repository performance report for methodology and limitations.
